Hostel Listing Site for KIU Ishaka Students
=========================================

A simple, mobile-first website to connect KIU Western Campus students with verified hostels in Ishaka, Bushenyi. Built with HTML, Tailwind CSS, and hosted on Vercel.

Features:
- List hostels with photos, price, facilities
- Filter by location, budget, room type
- WhatsApp direct booking to landlords
- Admin tracking via Google Sheets

Purpose:
- Help KIU students find hostels fast
- Help Ishaka landlords fill rooms
- Commission-based model (50k per booking)

Tech:
- Frontend: HTML + Tailwind CSS
- Hosting: Vercel
- Tracking: Google Sheets + WhatsApp API
